## 这本书和别的有什么不一样

网上给大学生的建议有两类：一类是「你要努力」，一类是「快跑」。两类都没告诉你**具体代价**。

这本书的每一条，都按同一个格式写：

| 字段 | 回答什么问题 |
|---|---|
| 成本 | 要花多少钱、多少时间、要不要长期坚持 |
| 说人话 | 这件事到底是什么，不用术语讲 |
| 收益 | 具体的数字或条文原文，查不到就写「没有公开数据」 |
| 为什么 | 这条结论背后的机制 |
| 证据等级 | A（有官方原文）/ B（有统计）/ C（只有经验） |
| 来源 | 机构、文件名、条款号、链接 |
| 备注 | 什么情况下这条不适用 |

**还有一维是这本书独有的：口径。**

成年人做错事，代价多是钱和时间。学生在 18–22 岁做的几个决定——选专业、专升本、要不要复读——是**半可逆或不可逆**的。所以每条都会标出来：这个选择，做错了能不能退回来。

## 怎么用这本书

**如果你是学生**：遇到一个具体选择，先在目录里找对应章节，看「成本」和「口径」两行。不可逆的选项值得多花一晚上查；可逆的选项不用纠结。

**如果你是家长**：第 1 章那 5 条，多数是孩子到大三才来问、但窗口已经关了的。提前一年看，价值最大。

**如果你想贡献**：先读 [WRITING.md](WRITING.md)。核心要求只有一条——**能查到的才写，查不到的说不确定**。

## 数据来源

本书优先引用以下一类来源，不用自媒体二手转述：

- **教育部**：普通高等学校学生管理规定（教育部令第 41 号）等规章原文
- **学信网**：学籍、学历查询与认证
- **人社部**：就业、社保、职业资格相关政策
- **各省教育厅**：专升本计划、转学备案
- **国家统计局**：就业与收入统计

每条的具体出处，写在条目的「来源」行。

## 收录标准

**写进来**：18–25 岁会真实遇到、且做错代价大的选择。

**不写**：纯知识类（那去读书）、需要专业资质的（看病打官司，直接给求助渠道）、已经说烂又没有新数据的。

## 免责

本书汇总公开信息，供参考；不构成法律、医疗、投资建议。涉及具体个案——退学、劳动仲裁、医疗——请咨询学校相关部门或专业机构。
