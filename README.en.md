## What makes this different

Advice for students online comes in two flavors: "you should work harder" or "run away." Neither tells you **what it actually costs**.

Every entry in this book follows the same seven-field format:

| Field | What it answers |
|---|---|
| Cost (成本) | How much money, how much time, does it need long-term discipline |
| Plain language (说人话) | What this actually is, without jargon |
| Benefit (收益) | Concrete numbers or the verbatim text of regulations; if not findable, says "no public data" |
| Why (为什么) | The mechanism behind this conclusion |
| Evidence grade (证据等级) | A (official text) / B (statistics) / C (experience only) |
| Source (来源) | Agency, document, clause number, link |
| Notes (备注) | When this entry does not apply |

**One dimension is unique to this book: reversibility (口径).**

Adults who make mistakes mostly lose money and time. At 18–22, a student's decisions — major choice, transfer, whether to repeat a year — are **semi-reversible or irreversible**. So every entry is tagged: can you undo this if you get it wrong?

## Build it yourself

Requires Node.js ≥ 18. PDF additionally needs Chrome or Edge.

```bash
git clone https://github.com/yanwaiyue-name/students-howtolivebetter
cd students-howtolivebetter
node tools/build-all.mjs
```

Output in `dist/`. Zero third-party dependencies (except `undici` for proxy support in the link checker).
