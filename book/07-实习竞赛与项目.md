# 07. 实习、竞赛、项目：哪个更值钱

这一章回答一个具体问题：**在有限的时间里，三件事只能选一件，选哪个。**

大多数人的困境不是"不想努力"，而是"努力的方向太多，每个都浅尝辄止"。这一章按"能不能被验证"排序——能被陌生人验证的，比只能自己说的值钱。

本章条目：

- 第 1 条：三件事的回报结构完全不同
- 第 2 条：实习的价值在"真实工作过"，不在公司名气
- 第 3 条：竞赛要看是否在"白名单"里
- 第 4 条：项目作品的关键是可访问、可复现
- 第 5 条：时间怎么分配：一个能过筛子的组合

---

### 1. 三件事的回报结构完全不同
<!-- 成本标签: 钱=少 时间=多 毅力=是 收益=大 口径=可逆 -->
- 成本：三者都要投入 3–12 个月，且高度挤占彼此的时间。
- 说人话：实习给你的是"职场经历"（证明你能在真实环境里交付）；竞赛给你的是"可比较的名次"（有官方榜单，第三方能验证）；项目给你的是"可查看的作品"（对方能点开看）。三者的共同点都是"提供第三方可验证的证据"，区别在于验证的难度。
- 收益：判断标准可以统一成一个问题——**一个陌生 HR 花 30 秒，能不能验证你说的这件事是真的？** 竞赛有获奖名单可查，最快；开源项目有链接可点，次之；实习经历需要背调，最慢。
- 为什么：招聘的本质是降低误判风险。所有能被快速验证的证据，都比"我自己说我很努力"有用。这就是为什么同样是三个月，做一个有 GitHub 链接的项目，往往比在一家不知名公司实习更有效。
- 证据等级：C
- 来源：没有公开数据能证明三者的相对回报。本条为经验归纳，判断依据是招聘实践，例：<https://www.ncss.cn/>（检索路径：国家大学生就业服务平台 → 政策 / 就业指导栏目）
- 备注：这条是 C 级经验判断，**没有权威数据**。不同行业差异极大——金融、国企更看重实习（有留用机制），互联网技术岗更看重项目与竞赛。必须按目标行业调整。

### 2. 实习：价值在"真实工作过"，不在公司名气
<!-- 成本标签: 钱=少 时间=多 毅力=是 收益=大 口径=可逆 -->
- 成本：多数实习补贴较低（部分无薪），且要占用一个学期或整个暑假。
- 说人话：实习的核心价值不是"我在这家公司待过"，而是"我在真实的生产环境里交付过东西"。大厂实习的价值在于流程规范、有导师带；小公司实习的价值在于能碰核心业务、独当一面。两者都能写成简历，但要说清楚你具体做了什么。
- 收益：判断一段实习是否值得，看三个问题：① 有没有明确的产出物（代码、文档、方案）；② 有没有人能给你写推荐；③ 有没有机会接触到这个行业的真实工作方式。三个都"没有"的实习，价值接近零。
- 为什么：企业招应届生时的核心担忧是"能不能干活"。实习是唯一能直接证明这一点的经历——因为它发生在真实的工作环境里，有 deadline、有协作、有交付标准。
- 证据等级：C
- 来源：没有公开数据可用于跨行业比较实习价值。本条为招聘实践经验归纳，例：<https://www.ncss.cn/>（检索路径：国家大学生就业服务平台 → 政策 / 就业指导栏目）
- 备注：这条是 C 级经验判断。**注意区分"实习"与"打杂"**：如果三个月里你的工作是复印、订餐、整理表格，那这段经历在简历上几乎无法展开写。

### 3. 竞赛：先看是否在"白名单"里
<!-- 成本标签: 钱=少 时间=多 毅力=是 收益=中 口径=可逆 -->
- 成本：报名费、差旅费（部分赛事），以及 1–6 个月的备赛时间。
- 说人话：竞赛的含金量差别极大。判断标准是：这个赛事是否被官方认可（是否在教育部或行业协会公布的赛事名单里）。在白名单里的赛事，获奖可以写进简历、部分学校还能折算学分或加综测；不在名单里的"国际大赛"，可能只是商业机构办的。
- 收益：教育部每年公布全国普通高校大学生竞赛名单（俗称"白名单"），列入的赛事具有官方认可度。部分赛事获奖在保研、评奖中有明确加分，具体规则由各校规定。
- 为什么：竞赛的价值来自"可比较"——有官方榜单，第三方能查证。一旦赛事不在名单里，这个"可比较性"就消失了，获奖也就变成了自说自话。
- 证据等级：B
- 来源：教育部年度公布的全国普通高校大学生竞赛名单（逐年更新，名单会调整）。查询入口：中国高等教育学会（高校竞赛评估与管理体系研究工作组）. <https://www.cahe.edu.cn/>（检索路径：中国高等教育学会 → 高校竞赛评估与管理体系研究工作组）
- 备注：这条是 B 级——名单每年调整，**今年在名单里不代表明年还在**，报名前查当年名单。另外，同一个赛事的不同赛道含金量也不同，省赛和国赛差别很大。

### 4. 项目作品：关键是可访问、可复现
<!-- 成本标签: 钱=少 时间=中 毅力=是 收益=大 口径=可逆 -->
- 成本：几乎零成本（GitHub 免费、域名可选），主要投入是时间。
- 说人话：一个项目要能当证据用，必须满足两条：**对方能点开看**（有链接，不是压缩包），**对方能跑起来**（有 README、有安装步骤、有截图）。很多人做了一堆项目却没法展示，就是因为缺这两条。
- 收益：判断一个项目作品是否合格，用一个陌生人的视角测一遍：给他链接，他能不能在 5 分钟内明白这是什么、怎么用、做了什么。做不到就是没做完。
- 为什么：项目是三者里**唯一完全由你控制**的证据。实习要看公司给不给机会，竞赛要看你能不能获奖，只有项目，你可以随时开始、随时改进、随时展示。
- 证据等级：C
- 来源：没有公开数据可量化项目作品的回报。本条基于开源社区通行实践（README 规范、可复现性），例：<https://docs.github.com/zh/repositories>
- 备注：这条是 C 级经验判断。**最常见的错误是"项目做了但没写 README"**——在招聘方眼里，没有 README 的项目等于不存在。

### 5. 时间怎么分配：一个能过筛子的组合
<!-- 成本标签: 钱=少 时间=多 毅力=是 收益=大 口径=可逆 -->
- 成本：按这个组合走，意味着放弃一部分"什么都参加"的选项。
- 说人话：如果目标是求职，一个可行的组合是：**一段真实实习 + 一个可访问的项目 + 一次白名单赛事参与**。三者的作用不同，互相不可替代：实习证明你能在团队里干活，项目证明你有独立交付能力，竞赛证明你在同类人里的相对位置。
- 收益：这个组合的检验方式是——把这三样放进一份一页纸的简历，能不能填满且不重复。填不满说明还缺东西，重复说明有一样是多余的。
- 为什么：招聘筛选通常是分层的：先看有没有硬性资格（学历、专业），再看有没有证据（项目、实习），最后看证据的质量。三者覆盖了不同层，所以组合比单点突破更稳。
- 证据等级：C
- 来源：没有公开数据支撑这一具体组合。本条为策略性归纳
- 备注：这条是 C 级经验判断，**不是普适公式**。考研、考公、出国三条路对这三样的权重完全不同——考研几乎不看实习，出国更看重科研与 GPA。必须先确定去向，再决定投什么。
